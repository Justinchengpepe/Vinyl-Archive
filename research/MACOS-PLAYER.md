# Vinyl Archive：macOS 黑胶播放器

2026-10-14。基于 Justinchengpepe/music-player 的本地改造。

## 最终方向

以原来的 3D 黑胶馆为主体：完整专辑封面唱片套、抽出的黑胶、原有歌手切换。不再增加独立的传统音乐首页。精选仍以欧美艺人为主，保留这 30 位的策展专辑；Search 和 ⌘K 可搜索网易云全站的歌手、专辑，非精选歌手直接拉取曲库专辑，只展示正式录音室专辑，排除单曲、EP、现场、混音、精选；同名发行优先标准版，只有豪华版时保留一张。唱片环按数量扩展间距，正面唱片位置保持不变。搜索结果支持继续分页，单张专辑可直接放入黑胶馆。

播放页沿用原来的黑胶、唱针和同步歌词；用真实封面做模糊色彩背景，减少装饰粒子，保持文字与播放控件可读。

## 已实现

- Electron macOS 外壳，本地 Node 服务在独立 utility process 中自动启动；渲染器关闭 Node 权限并启用 sandbox/context isolation。
- 本地服务只监听 127.0.0.1，使用每次启动生成的随机请求标记；端口保存在本机，以便登录缓存的网页来源保持一致。
- macOS 关闭窗口隐藏，Dock 可重新显示；⌘Q 退出并停止服务。
- 黑胶馆增加全站歌手/专辑搜索与分页；Adele 的搜索和 22 张专辑已用真实接口验证。
- 切换歌手时取消旧结果的应用，避免较慢响应覆盖新的选择；选曲也避免播放地址乱序覆盖。
- 专辑搜索兜底要求艺人 ID 与专辑名匹配，避免短标题匹配到其他艺人的专辑。
- 静态资源白名单，配置、凭证、源码和依赖不能通过 HTTP 下载。
- 专辑 3D 贴图通过限制来源的同源代理加载，避免桌面渲染器的跨域图片限制；限制图片大小和请求时间。
- iTunes 封面请求最多等待 5 秒，失败后使用网易云封面。

读过 YesPlayMusic 的 src/background.js、src/utils/Player.js，以及 API 实现的 song_url_v1.js、util/crypto.js。本地现有接口库中 weapi 是 AES + RSA 的请求封装，eapi 使用 AES 与摘要格式封装；这些属于接口兼容层，不是音频解码器。本项目已经依赖这类接口实现，没有必要重新反编译网易云客户端来制作桌面软件。

## 运行

```sh
npm install
npm run desktop
```

网页调试：`npm start`，打开 http://localhost:8088。

macOS 本机架构打包：`npm run build:mac`。构建产物在 dist/mac-arm64/Vinyl Archive.app（本机 Apple Silicon）。这是未签名的开发版本；尚未做 Apple 公证或自动更新。

## 验证与后续

HTTP 回归覆盖公开资源、凭证隔离、路径访问限制、非精选艺人和搜索接口失败备用路径。桌面 smoke 验证自动启动、页面结构与 renderer Node 隔离。真实网易云扫码登录及需账号权益的完整歌曲播放仍需本人登录验证，不能用匿名请求代替。

完整播放与音质由歌曲版权、账号权益和网易云返回结果决定。已改掉“扫码解锁完整音质”的承诺。

登录凭证仍按原项目保存在本机网页 localStorage。正式版可迁移到 macOS Keychain/safeStorage，再增加播放队列持久化、原生快捷键、当地音乐文件和逐词歌词。

依赖已做兼容范围内的 npm audit fix；旧 API 库的若干传递依赖仍有审计项，不强制降级到不兼容版本。当前产物用于本机开发验证，尚未完成公开发行检查。

## 2026-10-15 歌手选择入口

参考 [YesPlayMusic 歌手页](https://github.com/qier222/YesPlayMusic/blob/master/src/views/artist.vue) 的肖像与排版层级，以及 [Cider](https://github.com/ciderapp/Cider-2) 的桌面音乐应用方向，自行实现肖像式选择入口，未复制项目代码。默认显示选人界面并定位到上次的歌手；大幅肖像、侧面透视、统一中性色文字与进入唱片馆按钮。保留全站搜索入口，支持方向键、触摸及低敏感度滚轮。减少动态效果时直接切换，图片失效时用姓名首字母兜底。新增 8 项组件交互回归，覆盖记忆位置、循环切换、键盘、肖像预览、滚轮、弹窗隔离、搜索歌手返回和失败重试。

根据后续反馈，选人页再次精简：移除标题说明、数字计数、分类标签与底部文案，只保留肖像、歌手名和进入/切换控件。搜索继续使用全局顶栏入口。

## 2026-10-15 流动播放背景

播放页从专辑封面采样五组有区别的颜色，绘制缓慢移动、旋转和融合的多层椭圆色场。切换专辑时对颜色做连续过渡；文字前方保留暗色遮罩。绘制画布最长边限制为 480 像素、最多 24 fps，暂停、退出播放页、窗口隐藏或系统启用减少动态效果时停止循环。新增 7 项回归测试，覆盖取色、缺失封面、时间变化、播放/可见性生命周期、减少动态效果和循环清理。
## 多平台音乐账号（2026-10-15）

- 将右上角登录入口改为四个平台的统一账号面板；默认只展示平台与状态，按需展开详情。
- 网易云沿用已有扫码接口；切换平台或关闭面板会取消轮询并使过期响应失效。
- Apple Music 通过服务端 ES256 签名与 MusicKit v3 SDK 调用 `authorize()` / `unauthorize()`；无开发者配置时明确标注，未进行真实账号授权测试。
- Spotify 使用随机 state、S256 PKCE；桌面版专用沙盒窗口拦截准确回调路径，网页版同时校验消息 origin、source、state。公开 Client ID 可在面板填写，无需 Client Secret；缺少真实 Client ID，尚未实测平台授权。
- QQ 音乐仅在 macOS 版创建隔离的官方网页会话，Cookie 不交给播放器页面；此入口尚不提供 QQ 音乐的黑胶馆内播放。
- 当前搜索、专辑和播放来源仍为网易云。跨平台播放、歌单同步属于后续适配，界面有明确提示。
- 参考：[Apple MusicKit](https://developer.apple.com/musickit/)、[Spotify PKCE](https://developer.spotify.com/documentation/web-api/tutorials/code-pkce-flow)、[QQ 音乐开放平台](https://developer.y.qq.com/)。


## 统一播放层（2026-10-15，后续更新）

- 新增 `js/playback.js`：统一传输状态、控制、事件、来源选择、严格的同录音匹配、取消过期请求、先停后播。
- 网易云现可用，优先当前播放接口，保留试听标识与歌词偏移。
- Apple Music 适配 MusicKit 正式播放接口；无账号授权或无 DRM 环境时不可选，尚未进行真实订阅账号播放验证。
- Spotify 使用官方设备播放 API，需要开发者应用、Premium 和新播放权限；需用户手动选择该来源，不自动把声音切换到外部设备。尚无真实账号验证。
- QQ 音乐当前仍限官方网页会话。四个平台目录聚合、QQ 播放和跨平台歌单同步尚未完成。
- Apple 公开商店试听的用途限定为商店内容推广，因此未作为后台替代音源。
- 验证：58 项测试通过，涵盖音源回退、完整曲目优先、试听标注、错误/取消、快速换歌、DRM 检测、Spotify 当前设备和授权范围。

## 黑胶启动动画（2026-10-15）

- 新增共享 CSS 黑胶/纸套、唱片纹理、金色标签、掠光与简约字标；未引入第三方运行库或远程动画素材。
- macOS 主窗口先加载随包提供的本地启动页，再启动后端并进入播放器；网页首屏使用同一视觉。首屏等待艺人数据、当前头像解码（最多 650ms）和首帧就绪，常规最短展示 1.1 秒，随后 600ms 淡出。
- 交互区在启动期间 inert；慢启动 18 秒后可重试；脚本错误不会被迟到的数据请求掩盖；减少动态效果模式取消转动和装饰等待。
- GitHub 实现参考：[loadingio/css-spinner](https://github.com/loadingio/css-spinner)、[lukehaas/css-loaders](https://github.com/lukehaas/css-loaders)。仅参考纯 CSS 的轻量实现方式，视觉与生命周期代码独立编写。
- 74 项测试通过，覆盖启动就绪、退出、慢加载、错误重试、重复回调及减少动态效果。

## 保留选择界面的胶套翻面与沉浸播放（2026-10-15）

- 保留原有选人轮播、3D 黑胶架、选中专辑和右侧曲目栏。浏览中的每张胶套正反两面共用原始封面纹理，选择动画也不会露出纯色背板。

- 99 项测试覆盖原位投影、原图保留、动态配色、翻面返回顺序与既有功能。

### 翻面返回时的穿模修复

返回黑胶架前先用 280ms 将胶套翻正，期间保持黑胶隐藏；随后将胶套和黑胶作为整体移回架上。返回采用最近的等价角度，避免额外绕转一周。延迟载入的封面不再改写选中或返回中的缩放。新增测试覆盖完整翻面、中途返回、减少动态效果及多圈浏览后的角度连续性。

### 恢复原有造型

保留 0.012 深度的轻薄封面与原有专辑比例。恢复初版的悬停抽出、移开滑回及选中抽出的运动轨迹。默认与返回后在封面上沿微露弧边（露出高度约为封面高度的 7%），悬停时抽出；移开后滑回微露位置。唱片随封面一起转动，压薄到封面内部，正反两面均遮住开口下方的黑胶。播放页的旋转唱片保留，翻正再返回的防穿模修复也保留。
